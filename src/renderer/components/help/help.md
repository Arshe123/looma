# Looma 帮助文档

Looma 是一款本地优先的 Markdown 笔记应用。它不把笔记锁进私有数据库，而是直接使用你选择的文件夹作为工作空间：笔记仍然是普通的本地 Markdown 文件，随时可以用其他编辑器、Git 或同步工具继续处理。

除了写作与整理，Looma 还内置了 AI Agent。它可以在当前工作空间内检索资料、阅读文件并回答问题；需要修改文件时，会先给出差异提案，等你逐项确认后才会写入磁盘。

> 下文中的快捷键均以 Windows / Linux 的 `Ctrl` 写法为准，macOS 上请使用 `⌘`（Command）代替。

## 1. 开始使用

### 1.1 打开或新建工作空间

1. 启动 Looma，点击「打开工作空间」并选择保存笔记的文件夹；也可以选择「新建工作空间」创建一个空目录。
2. 打开后，左侧文件树会展示该文件夹原有的目录结构，文件保持原样，不会被移动或转换。
3. 可以从「最近工作空间」快速回到之前用过的文件夹，也可以在命令面板中切换或新建工作空间。每个工作空间在独立窗口中打开。

### 1.2 新建第一篇笔记

- 在文件树中点击新建按钮（或按 `Ctrl + N`）创建 Markdown 文件，输入文件名（如 `我的笔记.md`）后回车。
- 也可以直接新建文件夹来组织笔记。
- 除了 Markdown，Looma 也能编辑 `.txt` 纯文本文件。

### 1.3 修改会自动保存

Looma 的编辑是自动保存的，无需手动点击保存按钮。按 `Ctrl + S` 可以随时强制保存当前文件。所有内容都会写回工作空间中的本地文件。

## 2. 界面总览

Looma 的界面由三部分组成：

- **左侧边栏**：文件树、大纲、AI 助手三个面板，点击图标切换。
- **中间标签页**：已打开的笔记以标签页形式排列，可同时打开多篇笔记。
- **右侧主区域**：当前笔记的编辑区，支持预览、源码和分栏三种视图。

左下角还有**主题切换**和**更多**菜单（帮助、检查更新、系统设置等）。

### 2.1 侧边栏

- **文件**：浏览、新建、重命名、移动、复制和删除文件与文件夹。
- **大纲**：展示当前 Markdown 笔记的标题结构，点击标题即可跳转。仅在打开 Markdown 文件时可用。
- **AI 助手**：与 Agent 对话，基于当前工作空间进行问答和文件操作。

### 2.2 主题

点击左下角的主题按钮可在「浅色 → 深色 → 跟随系统」之间循环切换。你可以在系统设置中进一步调整外观。

### 2.3 标签页与状态恢复

Looma 会记住上次的工作状态：再次打开同一个工作空间时，会自动恢复上次的标签页、目录展开状态、每篇笔记的编辑位置和视图模式。

## 3. 笔记编辑

### 3.1 三种视图模式

同一篇笔记可以在三种模式间切换（右下角切换按钮）：

| 模式 | 说明 |
| --- | --- |
| 预览 | 富文本所见即所得（默认）。直接编辑标题、列表、表格、图片等，无需面对 Markdown 语法 |
| 源码 | 纯 Markdown 源码编辑，适合精确调整格式 |
| 分栏 | 左右同时显示源码与预览，支持**同步滚动**，拖动中间分隔条可调整两侧宽度 |

切换视图不会丢失内容：源码和预览始终是同一份 Markdown，编辑任意一侧都会实时同步到另一侧。

### 3.2 富文本编辑

在预览模式下，你可以直接：

- 使用工具栏或行内菜单设置**标题级别、加粗、斜体、删除线**；
- 创建**有序/无序列表、任务清单**（勾选框可直接点击切换完成状态）；
- 插入和编辑**表格**（选择行列数、增删行列）；
- 插入**代码块**（支持语言标注与语法高亮）和**行内代码**；
- 设置**文字颜色**与**高亮**；
- 插入**图片**：可以选择本地图片、将图片文件拖入编辑区，也可以直接粘贴系统剪贴板中的图片；
- 输入 `[[` 插入对其它笔记的引用（见「笔记引用」）。

在富文本编辑器中粘贴 Snipaste 截图、系统截图或网页复制的图片时，Looma 会把图片保存到当前笔记同级的 `assets` 文件夹，并在当前光标位置插入引用。粘贴本地图片文件与拖入图片的处理方式一致；PNG、JPG、GIF、WebP 和 SVG 图片均受支持。

编辑器会显示**行号**，光标所在行会高亮，方便你对照源码与预览的位置。

### 3.3 快捷插入菜单

在编辑时，行内会出现一个「+」按钮，点击即可快速插入标题、列表、表格、代码块等常用元素。这个菜单共 9 个槽位，可以按 `Ctrl + 1` ～ `Ctrl + 9` 直接触发对应位置的操作。菜单的内容和顺序可以在「系统设置 → 编辑器」中自定义，每个槽位对应的快捷键也可以在快捷键中心修改或停用。

### 3.4 大纲导航

打开侧边栏的「大纲」面板，可以看到当前笔记的标题结构（一级到六级标题）。长文写作时，用大纲快速跳转到任意章节，也可以拖动大纲标题调整层级（如需要）。大纲仅在当前打开的是 Markdown 文件时可用。

### 3.5 大文件

长笔记不会卡住界面：大文件按块加载、按块渲染，打开时不必等待全部内容处理完成，滚动和编辑依然流畅。

### 3.6 纯文本文件

`.txt` 等纯文本文件可以在 Looma 中直接查看和编辑（以纯文本编辑器打开，不支持富文本渲染）。

## 4. 文件管理

### 4.1 文件树操作

- **新建**：点击文件树顶部的新建按钮创建文件或文件夹；也可以按 `Ctrl + N` 新建文件。
- **重命名**：选中后按 `F2`，或从右键菜单中选择「重命名」。
- **移动**：直接拖拽文件/文件夹到目标目录，也可以剪切后粘贴。
- **删除**：选中后按 `Delete` 或从右键菜单删除。删除的文件会先进入工作空间的**回收站**，不会立即丢失（见下文）。
- **复制 / 剪切 / 粘贴**：选中文件后按 `Ctrl + C` / `Ctrl + X` / `Ctrl + V`，或使用右键菜单。粘贴时可以直接从系统剪贴板读取文件；如果剪贴板中是 Snipaste 截图、系统截图或网页复制的图片，则会将其保存为独立图片文件。

部分文件操作支持撤销和重做：按 `Ctrl + Z` 撤销最近一次文件操作，按 `Ctrl + Y` 重做（在文本编辑框内时，这两个快捷键仍用于文字撤销/重做，不会误触文件操作）。

### 4.2 拖入文件

- 将**外部文件**拖入文件树：文件会被复制到拖入位置所在的目录（原文件不受影响）。
- 将**图片**拖入打开的笔记：图片会被复制到当前笔记同级的 `assets` 文件夹，并在拖入位置插入引用；这一行为与在富文本编辑器中粘贴图片文件一致。

### 4.3 回收站

删除的文件会进入工作空间的回收站，你可以：

- 在回收站中**恢复**误删的文件（恢复到原位置或指定目录）；
- 或**彻底清空**回收站，永久删除这些文件。

## 5. 笔记引用

Looma 支持在笔记之间建立可移植的引用链接，把散落的笔记连成一张知识网络。

### 5.1 插入引用

在富文本预览中直接输入 `[[`，会弹出笔记选择框：它会列出工作空间内的全部笔记，输入关键字过滤后回车（或点击）即可。Looma 会插入一条**标准的 Markdown 链接**（不是 Obsidian 专属语法），并且自动计算相对路径——即使笔记在子目录中，链接也能正确指向目标。

### 5.2 链接语法

手写引用链接时，支持以下形式（路径相对于当前笔记所在目录，跨目录时使用 `../`）：

```
[文字](目标笔记.md)              # 打开笔记
[文字](目标笔记.md#标题)          # 跳转到指定标题
[文字](目标笔记.md#L12)          # 跳转到第 12 行
[文字](目标笔记.md#L12-15)       # 跳转到第 12～15 行
```

因为使用标准 Markdown 语法，这些链接在任何 Markdown 编辑器、Git 或网页渲染器中都能正常解析，笔记迁移到别处也不会失效。

### 5.3 悬停预览与跳转

- 鼠标**悬停**在引用上，会弹出浮窗预览目标笔记的内容片段（渲染后的效果，不是源码）。
- **点击**引用即可打开目标笔记并跳转到对应位置（标题或行号）。
- 在引用上**右键**可以快速复制完整的可移植链接。

### 5.4 外部链接

笔记中的外部网页链接（`http(s)://`）始终使用系统默认浏览器打开，不会在 Looma 内跳转，也不会弹出新的 Looma 窗口。

## 6. 图片与媒体预览

- 直接**预览**常见媒体文件：图片支持 `ico`、`png`、`jpg`、`jpeg`、`gif`、`webp`、`svg`；视频支持 `mp4`、`webm`、`ogg`。
- 查看图片时支持**滚轮缩放、拖动查看、双击复位**，界面会显示图片的尺寸、比例与文件大小。
- 在笔记中插入的本地图片会引用工作空间内的文件，随工作空间一起移动和备份。

## 7. 快捷键速查

| 快捷键 | 操作 |
| --- | --- |
| `Ctrl + O` | 打开工作空间 |
| `Ctrl + Shift + N` | 新建工作空间 |
| `Ctrl + Shift + P` | 打开命令面板 |
| `Ctrl + N` | 新建文件 |
| `Ctrl + S` | 保存当前文件 |
| `Ctrl + Z` / `Ctrl + Y` | 撤销 / 重做文件操作 |
| `Ctrl + C` / `Ctrl + X` / `Ctrl + V` | 复制 / 剪切 / 粘贴文件（选中文件时） |
| `F2` | 重命名选中的文件 |
| `Delete` | 删除选中的文件（进入回收站） |
| `Ctrl + 1` ～ `Ctrl + 9` | 触发快捷插入菜单对应槽位 |
| `Ctrl + =` / `Ctrl + -` | 标题级别提升 / 降低 |

编辑器快捷键可以在「系统设置 → 编辑器 → 快捷键中心」中集中查看、启停或修改，也可以一键恢复默认设置。若新组合键与现有设置冲突，Looma 会保留原配置并提示你重新选择。

## 8. AI 助手与 Agent

Looma 的 AI 不只聊天，还能理解整个工作空间。它通过本地 RAG 索引检索你的笔记，调用工具读取文件、搜索内容，并在修改文件前征求你的同意。

### 8.1 第一步：配置 AI

打开「系统设置 → AI 设置」，选择模型提供商并完成配置。对话模型与向量模型分开设置，可以按隐私、速度和成本自由组合。

- **提供商**：Ollama（本地）、OpenAI、DeepSeek、通义千问，或「自定义 HTTP API」（兼容 OpenAI 协议的服务）。
- **对话模型（LLM）**：负责理解问题、调用工具和生成回答。
- **向量模型（Embedding）**：负责把笔记切块转为向量，用于 RAG 检索。
- 使用 **Ollama** 时，可以直接在设置中查看本机已安装的模型，或一键下载内置推荐模型（如 `qwen2.5:7b`、`bge-m3` 等）。
- 使用云端服务时，填写对应的 Base URL、API Key、模型名；高级选项可调整温度与最大输出 token。

只使用笔记编辑功能时，可以不配置任何 AI。

### 8.2 第二步：使用 AI 助手

打开侧边栏的「AI 助手」面板，在输入框中直接提问。Agent 会基于**当前工作空间**回答，例如：

- 「总结 `notes/` 目录下所有关于项目的笔记」
- 「找出所有提到过 XXX 的地方，并按日期整理」
- 「帮我把这篇笔记改写成更简洁的版本」

首次使用时，AI 助手会提示你为当前工作空间建立索引。建议按提示建立，这样 Agent 可以快速检索到相关内容。

### 8.3 第三步：建立知识索引（RAG）

每个工作空间有独立的本地索引，用于语义检索：

- **构建方式**：首次可全量构建；之后使用**增量更新**同步新增或修改的文件；构建失败的条目可以单独「重试失败」。
- **范围控制**：可以只重建单个文件，也可以重建整个索引。
- **状态透明**：索引页面会列出每个文件的索引状态——已索引、未索引、已过期、已删除、失败或被忽略，你可以随时查看。
- **内容可见**：可以检查检索切块及其来源，清楚 AI 实际读到了什么。
- **设置**：在索引设置中可以调整切块大小（默认 800 字符）、重叠长度（默认 100）与切块策略（固定大小或按 Markdown 结构切分），修改后重建索引即可生效。

### 8.4 Agent 如何工作

Agent 在执行任务时会按需使用以下工具，并在对话中展示执行过程：

| 工具 | 作用 | 风险 |
| --- | --- | --- |
| `rag_search` | 检索当前工作空间的知识索引，获取与问题相关的片段 | 只读 |
| `workspace_list` | 列出工作空间内的文件和目录 | 只读 |
| `workspace_search` | 用纯子字符串搜索文件名和 UTF-8 文本内容 | 只读 |
| `file_read` | 读取工作空间内文本文件的指定范围 | 只读 |
| `file_patch` | **提议**创建或修改文本文件（不会直接写入） | 需审批 |

Agent 只能访问当前工作空间内的文件：路径会被严格校验，越界（绝对路径、`..` 逃逸、内部目录）的访问会被拒绝。

### 8.5 执行过程与参考来源

- 对话中会以**时间线**展示 Agent 的每一步：检索、列目录、搜索、读文件、修改提案等，每一步都能看到工具调用与结果。
- 回答底部会列出**参考来源**，展开可以看到命中的切块内容；点击来源可以直接打开对应的笔记。
- Agent 执行中遇到问题时，会收到失败原因并自行调整方案，而不是直接放弃。

### 8.6 文件修改审批

**Looma 不会让 Agent 在后台随意改动你的文件。** 当 Agent 提议创建或修改文件时：

1. 对话中出现**待审批项**，展示文件路径、操作类型（创建/更新）与完整的差异（diff）；
2. 你可以**批准**或**拒绝**每一项，也可以在「文件对比」页中查看改动前后的完整对比；
3. 只有你确认后，改动才会真正写入磁盘；审批超时未处理会自动作废，不会写入。

### 8.7 中断与继续

如果任务中途被打断（关闭应用、网络异常等），Agent 支持**从断点继续**：Looma 会为已执行的部分保存检查点，继续时创建新的运行，旧运行保持只读，未确认的文件修改不会被重复应用。

### 8.8 对话管理

- 可以保留**多组历史对话**，随时回来继续之前的话题；每组对话的草稿也会保留。
- 历史面板支持**搜索、置顶、收藏（可自定义分类）、归档**与分页浏览。
- 长对话会自动**压缩早期内容**，避免上下文超限，同时保留关键信息。

### 8.9 回答中的文字操作

在 AI 回答中选中文字，右键（或弹出菜单）可以选择：

- **加入对话框**：把选中的内容追加到提问框，基于它继续追问；
- **AI 解释**：让 AI 解释选中的这段内容。

## 9. 数据与隐私

- 笔记、工作空间配置和 RAG 索引默认保存在**本机**，索引按工作空间独立存放。
- 使用 **Ollama** 时，模型推理可以在本机完成，笔记内容不会离开你的电脑。
- 使用**云端模型**时，发送给模型的对话内容和必要上下文会交给所选服务商处理，请按其隐私政策使用。
- Agent 的文件修改始终需要你的审批，且被严格限制在工作空间目录内。

如果你只需要笔记编辑和媒体预览，可以不配置 AI，完全离线使用。

## 10. 获取更新

在左下角的更多菜单中选择「检查更新」。Looma 会读取 [GitHub Releases](https://github.com/Arshe123/looma/releases) 的最新正式版本；发现新版本后可前往发布页下载安装。

## 11. 常见问题

### 11.1 为什么大纲不可用？

大纲仅在当前打开的是 Markdown 文件时可用。纯文本文件没有标题结构，因此不会显示大纲。

### 11.2 删除的文件在哪里？

文件会先进入工作空间的回收站，可在文件树中恢复或彻底清空。彻底清空后文件将被永久删除，请谨慎操作。

### 11.3 AI 回答不准确怎么办？

- 确认已经为当前工作空间建立了索引，并在索引页面检查文件状态（是否有文件未被索引或已过期）。
- 提问时尽量给出范围，例如指定目录或文件名。
- Agent 回答中会展示参考来源，你可以点开核对它实际读到的内容。

### 11.4 Agent 修改文件安全吗？

安全。Agent 提出的所有文件修改都会先生成差异提案，由你逐项批准或拒绝后才会写入磁盘，并且 Agent 只能访问当前工作空间内的文件。建议在批准前查看「文件对比」页确认改动内容。

### 11.5 如何反馈问题？

请前往 [Looma GitHub 仓库](https://github.com/Arshe123/looma) 提交 Issue，或使用应用内的反馈入口。反馈时请附上复现步骤，帮助我们更快定位问题。
