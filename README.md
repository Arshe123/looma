# Looma

> 把散落在文件夹里的笔记，变成一套可以阅读、整理，也可以直接询问的个人知识空间。

Looma 是一款面向本地文件的桌面笔记应用。你不需要把资料导入某种专有格式：选择一个已有文件夹，就能继续使用其中的 Markdown、纯文本、图片和视频。笔记仍然是你熟悉的本地文件，换一个编辑器也照样能打开。

除了写作和整理，Looma 还内置了 AI Agent。它可以在当前工作空间内查找资料、阅读文件并回答问题；需要修改文件时，会先给出差异对比，等你确认后才会写入。

## 为什么选择 Looma

### 文件属于你

Looma 直接使用本地文件夹作为工作空间，不会把笔记锁进私有数据库。原有目录结构可以继续使用，也方便备份、同步或交给 Git 管理。

### 一份 Markdown，三种使用方式

同一篇笔记可以在富文本预览、Markdown 源码编辑和左右分栏之间切换。只想专心阅读时不必面对语法；需要精确调整时，也能随时回到源码。

### AI 不只聊天，还能理解整个工作空间

建立本地索引后，你可以直接询问散落在多篇笔记里的内容。Agent 会按需检索相关片段、列出文件、搜索工作空间并读取原文，回答中也能查看检索来源。

### 修改先审查，再落盘

当 Agent 建议创建或修改文件时，Looma 会展示文件差异和待审批项。只有经过你的确认，改动才会真正写入磁盘。

### 本地模型和云端模型都能用

你可以通过 Ollama 使用本地模型，也可以配置 OpenAI、DeepSeek、通义千问或兼容 OpenAI 协议的自定义服务。对话模型与向量模型分开设置，可以按隐私、速度和成本自由组合。

## 你可以用 Looma 做什么

### 写作与阅读

- 编辑 Markdown 和 `.txt` 纯文本文件。
- 在预览、源码和分栏模式间切换，分栏支持同步滚动与拖动调宽。
- 在富文本模式下直接处理标题、列表、任务清单、表格、代码块、颜色、高亮和图片。
- 用文档大纲快速浏览长文，点击标题即可跳转。
- 自定义快速插入菜单、快捷键和菜单顺序。
- 大文件按块加载，打开长笔记时不必等待全部内容渲染完成。

### 整理本地资料

- 把任意本地文件夹打开为工作空间，保留原来的目录结构。
- 在文件树中创建、重命名、移动和删除文件或文件夹。
- 同时打开多个标签页，并恢复上次的标签、目录展开状态、编辑位置和视图模式。
- 将外部文件拖入文件树完成复制；将图片拖进笔记即可插入。
- 使用大纲、最近工作空间和命令面板减少来回查找。
- 对部分文件操作执行撤销和重做。

### 预览图片与视频

Looma 可以直接预览 `ico`、`png`、`jpg`、`jpeg`、`gif`、`webp`、`svg`、`mp4`、`webm` 和 `ogg`。图片支持滚轮缩放、拖动查看和双击复位，界面会显示尺寸、比例与文件大小。

### 和自己的知识库对话

- 为每个工作空间单独建立本地 RAG 索引。
- 使用增量更新同步新内容，也可以重建单个文件或整个索引。
- 查看哪些文件已索引、已过期、失败或被忽略。
- 检查检索切块及其来源，知道 AI 实际读到了什么。
- 保留多组历史对话，随时回来继续之前的话题。
- 在回答中选中文字，直接加入下一轮提问或让 AI 解释。

### 让 Agent 协助处理文件

你可以让 Agent：

- 从多篇笔记中查找信息并整理答案；
- 阅读指定文件，解释或归纳其中的内容；
- 在工作空间内搜索文件名和正文；
- 提议创建、补充或修改文本文件；
- 在执行中遇到问题后调整方案，或从中断处继续。

文件修改始终需要审批。Looma 不会因为一次对话就让 Agent 在后台自由改动整个工作空间。

## 开始使用

1. 前往 [Releases](https://github.com/Arshe123/looma/releases) 下载适合你系统的安装包。目前 Looma 主要在 Windows 上测试。
2. 启动 Looma，选择“打开工作空间”，再选中保存笔记的文件夹。也可以新建一个空工作空间。
3. 从左侧文件树打开笔记，或创建第一篇 Markdown 文件。
4. 如果要使用 AI，进入“系统设置 → AI 设置”，选择模型提供商并完成配置。
5. 打开侧栏中的 AI 助手。需要让 AI 基于笔记回答时，按提示为当前工作空间建立索引。

## AI 与隐私

- 使用 Ollama 时，模型请求可以在本机完成。
- 使用云端模型时，发送给模型的对话和必要上下文会交给相应服务商处理，请按其隐私政策使用。
- RAG 索引按工作空间保存在本地，可在索引库中更新、重建或删除。
- Agent 的文件修改先生成提案，再由你逐项审批。

如果你只需要笔记编辑和媒体预览，可以完全不配置 AI。

## 常用快捷键

| 快捷键 | 操作 |
| --- | --- |
| `Ctrl + O` | 打开工作空间 |
| `Ctrl + Shift + N` | 新建工作空间 |
| `Ctrl + Shift + P` | 打开命令面板 |
| `Ctrl + N` | 新建文件 |
| `Ctrl + S` | 保存当前文件 |
| `Ctrl + 1` ～ `Ctrl + 9` | 执行快速插入菜单中对应位置的操作 |

编辑器快捷键可以在“系统设置 → 编辑器 → 快捷键中心”中查看、启停或修改。若新组合键与现有设置冲突，Looma 会保留原配置并提示你重新选择。
