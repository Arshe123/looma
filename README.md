# Looma

> 基于本地文件的 Markdown 笔记应用，让写作、知识整理与 AI 协作发生在同一个工作空间。

Looma 直接使用本地文件夹保存笔记，结合富文本编辑、知识检索和带长期记忆的 AI Agent。你可以专心写作，也可以让 Agent 查阅资料、整理内容或提出文件修改，再由你确认是否应用。

## 特色功能

### 本地文件，无需导入

选择一个文件夹即可作为工作空间，保留原有目录结构。笔记仍是普通的 Markdown 或纯文本文件，可以继续使用其他编辑器、Git 或同步工具。

也可以通过系统「打开方式 → Looma」直接编辑外部 `.md` 文件，无需创建工作空间。外部文件保存回原位置，不会自动加入工作空间索引或 AI 上下文。

### 一份 Markdown，三种编辑视图

在富文本预览、源码编辑和左右分栏之间切换，分栏支持同步滚动。标题、列表、任务清单、表格、代码块和高亮都可直接编辑；截图可以粘贴进笔记，图片显示大小会随 Markdown 保存。

笔记引用支持悬停预览和点击跳转，大纲与底部面包屑帮助你在长文和目录之间导航。

### 能查阅笔记，也能记住协作偏好的 Agent

Agent 可以列出目录、搜索文件名和正文、阅读文件并整理答案。建立本地 RAG 索引后，还能从多篇笔记中检索相关片段，并展示参考来源；索引不是使用 Agent 的前提。

三层长期记忆分别记录不同信息：

- **人格**：助手的身份与表达风格，全局共用，由你手动设定。
- **用户画像**：你的长期背景、习惯与偏好，跨工作空间共用。
- **工作空间记忆**：当前项目的目标、术语与约定，各工作空间独立保存。

画像与工作空间记忆支持自动维护、手动编辑、历史恢复和本机清理。可以分别关闭自动维护，减少反复介绍个人偏好与项目背景的需要。

### 文件修改由你决定

Agent 创建或修改笔记前会先生成差异提案。你可以查看完整对比，逐项批准或拒绝；只有批准后的改动才会写入文件。记忆的自动维护与笔记修改审批分开管理。

### 本地模型和云端模型自由组合

支持 Ollama、OpenAI、DeepSeek、通义千问及兼容 OpenAI 协议的自定义服务。对话模型与向量模型可以分别配置，支持的提供商会动态获取模型列表，也可手动指定模型。

只用笔记功能时，无需配置 AI；使用本地 Ollama 模型时，模型请求可以在本机完成。

## 日常使用

- **快速创建**：笔记模板支持日期函数和自定义变量，创建时可选择保存目录。
- **整理文件**：文件树支持复制、剪切、粘贴、拖动、按时间排序和全部折叠。
- **多篇笔记切换**：单击临时预览，双击或编辑后保留标签；支持拖动排序与关闭多组标签。
- **持续对话**：聊天自动总结标题，消息显示时间；历史支持搜索、置顶、收藏和归档。
- **阅读外观**：日间、夜间与跟随系统模式，三套配色和内置字体搭配，可调整阅读字号及行号显示。
- **保存与恢复**：自动保存、手动保存和异常退出恢复草稿；清空已有工作空间笔记时需确认保存。
- **媒体预览**：支持常见图片与视频，图片可缩放、拖动查看和双击复位。

## 开始使用

1. 从 [Releases](https://github.com/Arshe123/looma/releases) 下载适合 Windows 或 macOS 的安装包，具体构建以发布页为准。
2. 启动后打开已有文件夹或新建工作空间，从文件树打开笔记，也可以用模板创建新笔记。
3. 如需 AI，进入「系统设置 → AI 设置」配置提供商与模型，点击左侧 AI 图标打开右侧助手。
4. 按需建立知识索引，并在「系统设置 → 长期记忆」中设置协作偏好与项目背景。

## 数据与隐私

- 笔记、RAG 索引和长期记忆保存在本机。记忆位于应用数据目录，不随笔记文件夹自动同步。
- 使用云端模型时，对话与必要上下文（包括相关记忆）会发送给所选服务商，请勿在记忆中填写密码或密钥。
- Agent 的笔记修改需要审批；画像与工作空间记忆默认允许自动维护，可在设置中分别关闭。
- 本机记忆清理不可撤销，不会删除旧聊天、外部备份或服务商记录，也不等于彻底遗忘。

## 常用快捷键

Windows / Linux 使用 `Ctrl`，macOS 使用 `Command`。

| 快捷键 | 操作 |
| --- | --- |
| `Ctrl + O` | 打开工作空间 |
| `Ctrl + Shift + N` | 新建工作空间 |
| `Ctrl + Shift + P` | 打开命令面板 |
| `Ctrl + N` | 打开笔记模板选择器 |
| `Ctrl + S` | 保存当前文件 |
| `Ctrl + 1` ～ `Ctrl + 9` | 执行快捷插入菜单对应位置的操作 |

更多编辑器快捷键可在「系统设置 → 编辑器 → 快捷键中心」中查看和修改。
